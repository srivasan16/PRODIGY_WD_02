# PRODIGY_WD_02
Premium Stopwatch Web Application | HTML, CSS, JavaScript | Prodigy InfoTech Task-02

A modern and responsive Stopwatch Web Application built using **HTML**, **CSS**, and **JavaScript**.

## 🚀 Features

- ▶️ Start Stopwatch
- ⏸️ Pause / Resume
- 🔄 Reset Stopwatch
- 🏁 Record Lap Times
- ⭕ Animated SVG Progress Ring
- 🎨 Glassmorphism UI
- 🌙 Dark / Light Theme
- 📥 Export Lap Times to CSV
- 🏆 Fastest & 🐢 Slowest Lap Detection
- 💾 Local Storage Support
- 📱 Responsive Design

---


## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- SVG
- Font Awesome
